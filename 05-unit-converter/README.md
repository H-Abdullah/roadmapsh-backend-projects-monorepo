
## UNIT CONVERTER (UC)
Unit Converter is a simple website that can convert a value from various unit. This website is host-able locally from your own computer.

## PREREQUISITES
- Node version 18.9.1 (i tested on this version)
- Linux terminal (tested in linux only)
- Express Js

## HOW TO INSTALL
Copy this repo into your system by using git clone
```shell 
    git clone https://github.com/H-Abdullah/roadmapsh-backend-projects-monorepo
```

## HOW TO USE
In order to use the converter, follow the steps below:
1. Open a terminal at the root of the cloned repo then type:
```shell
    cd 05-unit-converter
```
2. You will find the API inside the directory then you make it executeable by using below command:
```shell
    chmod +x ./server.js
```
3. You can start using the api by running the command below:
```shell
    node server.js
```
4. Open a browser and type http://localhost:3000/ and start your conversion unit.


## FEATURES
What does this converter provides:
- Simple converter that run locally offline-mode
- Not so accurate converter, so use at your own risk
