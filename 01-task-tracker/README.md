## TASKLY - YOUR DAILY TASK TRACKER
Taskly is a single-line command interface that can be used in a terminal to track and mark all your daily task. It allows the user to create, update, mark and delete any task.

## PREREQUISITES
- Python3++
- Linux terminal (tested in linux only)

## HOW TO INSTALL
Copy this repo into your system by using git clone
```shell 
    git clone https://github.com/H-Abdullah/roadmapsh-backend-projects-monorepo
```

## HOW TO USE
In order to use the script, follow the steps below:
1. Open a terminal at the root of the cloned repo then type:
```shell
    cd 01-task-tracker
```
2. You will find taskly.py inside the directory then you make it executable by using below command:
```shell
    chmod +x ./taskly.py
```
3. You can start using the script by running the command below:
```shell
    python3 taskly.py --help
```

## FEATURES
You can do:
- Add new task
- Update task with new description
- Mark task with done or in-progress
- Delete task using id
- Clear all task
