## EXPENSE TRACKER
This is simple cli script that can track your daily spending with a single-line command. You can add, update, delete and view your spendings. You can even get the total of spendings that you have made since tracking it.

## PREREQUISITES
- Python3++
- Linux terminal (tested in linux only)

## HOW TO INSTALL
Copy this repo into your system by using git clone
```shell 
    git clone https://github.com/H-Abdullah/roadmapsh-backend-projects-monorepo
```

## HOW TO PLAY
In order to use the script, follow the steps below:
1. Open a terminal at the root of the cloned repo then type:
```shell
    cd 03-expense-tracker
```
2. You will find the script inside the directory then you make it executeable by using below command:
```shell
    chmod +x ./track-your-spending.py
```
3. You can start using the script by running the command below:
```shell
    python3 track-your-spending.py
```

## FEATURES
What does this script provides:
- A short single-line command to record your spending
- Provides basic command such as update, delete, view and even total spending
- Visually clean table is used to present the current spending
