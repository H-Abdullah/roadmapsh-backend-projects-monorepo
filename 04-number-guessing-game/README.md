
## NUMBER GUESSING GAME (NGG)
Number Guessing Game is a simple interactive cli terminal game. This game is visually clean and easily playable by pressing any number from your keyboard.

## PREREQUISITES
- Python3++
- Linux terminal (tested in linux only)

## HOW TO INSTALL
Copy this repo into your system by using git clone
```shell 
    git clone https://github.com/H-Abdullah/roadmapsh-backend-projects-monorepo
```

## HOW TO PLAY
In order to play the game, follow the steps below:
1. Open a terminal at the root of the cloned repo then type:
```shell
    cd 04-number-guessing-game
```
2. You will find game script inside the directory then you make it executeable by using below command:
```shell
    chmod +x ./guess-number.py
```
3. You can start playing the game by running the command below:
```shell
    python3 guess-number.py
```

## FEATURES
What interesting about this game:
- 4 different difficulty modes available [Easy, Medium, Hard, Infinity]
- Visually pleasing gameplay
- Can ask for 'hint' if you are getting stucked
